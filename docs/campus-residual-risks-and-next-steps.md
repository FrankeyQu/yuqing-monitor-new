# 残余风险与后续二开建议

## 1. Batch29 已收口项

| 项目 | 当前状态 |
| --- | --- |
| 登录页默认值 | 已移除前端预填账号、密码和验证码 |
| 旧任务默认开关 | 已改为环境变量控制，默认关闭 |
| 旧外部服务地址 | 已改为环境变量配置，默认空值 |
| API 文档 | 默认关闭，需显式配置后开启 |
| 试运行严格模式 | 新增 `prelaunch.strict`，用于部署前配置校验 |
| 校园权限 | 新增 `V1.19`，停用业务角色 `/campus/**` 粗粒度权限 |
| 学校初始化 | 新增 root 学校、常用部门和基础字典模板 |
| 监测任务中心 | 已支持监测任务、监测结果、负面告警和自动调度，默认只扫描已合法接入记录 |

## 2. 仍需学校确认

| 风险 | 当前状态 | 建议 |
| --- | --- | --- |
| 试运行管理员 | 本地仍有开发演示账号 | 学校确认管理员手机号、初始化密码策略和首次登录改密流程 |
| 学校组织 | 已有模板节点 | 按真实校名、学院、部门、负责人账号替换模板 |
| 角色矩阵 | 已有管理员、处置员、查看员最小模型 | 学校确认值班员、研判员、处置员、领导查看员、审计员边界 |
| 真实数据源 | 当前不启用真实外部调用 | 启用前逐项确认授权依据、范围、频率、额度、保留期限和责任部门 |
| 关键词和敏感词 | 只有字典分类模板 | 由学校提供并审核关键词包，避免误伤和过度采集 |
| 演示数据 | 仍保留本地 demo seed | 试运行库是否导入演示数据需单独确认 |

## 3. 后续二开建议

- 按学校真实组织补部门负责人、账号和数据范围过滤。
- 为按钮级操作增加前端权限控制，减少低权限角色看到不可用操作。
- 拆分 `IngestView.vue` 为来源、任务、白名单、运行日志、调用日志子组件。
- 为监测任务继续细化绑定策略、频率上限和学校正式关键词包。
- 在正式报告需求明确后接 Word/PDF 导出服务。
- 为登录、下载、导出、批量操作补更细审计策略。
- 真实公开网页采集只在白名单、授权依据、robots、栏目路径和频率确认后实现。
